
# سرویس بک‌اند آربیتراژ

این سرویس بک‌اند برای ارتباط برنامه آربیتراژ با دیتابیس SQL Server طراحی شده است.

## پیش‌نیازها

- Node.js (نسخه 14 یا بالاتر)
- SQL Server (یا Azure SQL Database)

## نصب و راه‌اندازی

1. نصب وابستگی‌ها:
   ```
   npm install
   ```

2. کپی فایل `.env.example` به `.env` و تنظیم متغیرهای محیطی:
   ```
   cp .env.example .env
   ```

3. در فایل `.env` اطلاعات اتصال به دیتابیس SQL Server را وارد کنید.

4. ایجاد جداول موردنیاز در SQL Server:
   - اسکریپت SQL موجود در فایل `setup.sql` را در SQL Server اجرا کنید.

5. راه‌اندازی سرور:
   ```
   node server.js
   ```

## API Endpoints

### معاملات

- `GET /api/trades` - دریافت لیست همه معاملات
- `POST /api/trades` - افزودن یک معامله جدید

### تنظیمات ربات

- `GET /api/bot-settings` - دریافت تنظیمات ربات
- `POST /api/bot-settings` - ذخیره تنظیمات ربات

### تنظیمات صرافی‌ها

- `GET /api/exchange-settings` - دریافت تنظیمات صرافی‌ها
- `POST /api/exchange-settings` - ذخیره تنظیمات یک صرافی

## امنیت

این سرور بک‌اند باید در یک محیط امن راه‌اندازی شود. در محیط تولید:

1. از HTTPS استفاده کنید
2. سیستم احراز هویت را پیاده‌سازی کنید
3. از فایروال و محدودیت‌های دسترسی IP استفاده کنید
4. اطمینان حاصل کنید که اطلاعات حساس در فایل `.env` ذخیره شده و هرگز در کنترل سورس قرار نمی‌گیرند
